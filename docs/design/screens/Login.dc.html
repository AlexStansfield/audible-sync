Reset your password

Audible Sync has no email, so a forgotten password is reset on the server it runs on. Run this command there. It sets a new password and prints it once in the terminal.

[RESET COMMAND]

Then sign in with the new password and choose your own under Your sign-in. Every other browser is signed out.
